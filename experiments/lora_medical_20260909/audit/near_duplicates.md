# 近重复候选检查结论（v2）

## 检查方法

- 范围：train_5000 与 val+test（200 条）之间的全部问题对（5000 × 200 = 100 万对）
- 度量：问题文本（strip 后）的字符二元组（bigram）集合的 Jaccard 相似度
- 阈值：J ≥ 0.5 输出为候选；≥ 0.4 作为复核档（更宽松）
- 实现位置：`prepare_data.py` 第 10 步；候选输出到 `audit/near_duplicates.jsonl`
- **候选仅供人工判断，不自动排除**；判定重复的按 `exclude_from=train` 写入排除清单

## 结果

**v1 全量预演（5000 × 200）：Jaccard ≥ 0.5 为 0 对，≥ 0.4 也为 0 对。**

正式 v2 生成时脚本以相同逻辑复算（结果见 `data/v2/manifest.json` 的 `near_duplicates.candidates` 字段与 `near_duplicates.jsonl`）。

结论：训练与验证/测试之间不存在字符层面的近重复问题。

## 判定原则（按需求约定）

- **同属一种疾病 ≠ 重复**：如"高血压吃什么药"与"高血压怎么治"是不同问题，不判重复
- 只有同一问题以不同措辞出现（语义等价的改写）才判重复
- 字符 bigram 相似度捕捉不到的**语义改写重复**（换词、换句式后字符重叠极低）不在本检查保证范围内——这是已知局限，语义级去重需要向量检索，超出本次工具范围。上游的归一化去重（去空白/标点/语气词后 md5）已覆盖最常见的轻量改写形态

## 与既有去重的关系

| 层 | 捕捉对象 | 状态 |
|---|---|---|
| 精确 md5 去重 | 完全相同的问题 | 已做（池级） |
| 归一化去重 | 去标点/语气词后相同的问题 | 已做（池级） |
| 近重复候选检查（本项） | 字符层面高度相似但未归一化相等的问题 | 人工判断，当前 0 候选 |
| 语义改写重复 | 换词换句式的等价问题 | 未覆盖（已知局限） |
